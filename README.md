# FastAPI Library API

A small REST API for managing books, built with **FastAPI**. It uses an in-memory Python dictionary instead of a database, as requested.

## Features

- List all books
- Add a book
- Get one book by ID
- Partially update a book
- Delete a book
- Request validation with Pydantic
- Clear `404 Not Found` errors for missing books
- Interactive API documentation via Swagger UI

> **Note:** Data is stored in memory and resets when the application restarts. This project is intended for practice and demonstration, not persistent production storage.

## Requirements

- Python 3.10+
- pip

## Setup

```bash
git clone https://github.com/AliAlishir/fastapi-library-api.git
cd fastapi-library-api

python -m venv .venv
```

Activate the virtual environment:

**Windows (PowerShell):**
```powershell
.venv\\Scripts\\Activate.ps1
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

Install dependencies and run the server:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.

- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/books` | Get all books |
| `POST` | `/books` | Create a book |
| `GET` | `/books/{book_id}` | Get a book by ID |
| `PATCH` | `/books/{book_id}` | Partially update a book |
| `DELETE` | `/books/{book_id}` | Delete a book |

The `{book_id}` path parameter is an integer. The API returns `404` when the requested book does not exist.

## Example requests

### Create a book

```bash
curl -X POST "http://127.0.0.1:8000/books" \\
  -H "Content-Type: application/json" \\
  -d '{"title":"Clean Code","author":"Robert C. Martin","published_year":2008}'
```

### Get all books

```bash
curl "http://127.0.0.1:8000/books"
```

### Get one book

```bash
curl "http://127.0.0.1:8000/books/1"
```

### Update a book

```bash
curl -X PATCH "http://127.0.0.1:8000/books/1" \\
  -H "Content-Type: application/json" \\
  -d '{"title":"The Little Prince (Updated)"}'
```

### Delete a book

```bash
curl -X DELETE "http://127.0.0.1:8000/books/1"
```

## Example book payload

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "published_year": 2008
}
```

The `id` is generated by the API and does not need to be included in the request body.
